# Python for AI & ML — Practice Scripts

Small scripts written while building foundational skills in data preprocessing, 
model building, and core ML workflow steps, as part of my M.Sc. Data Science coursework.

| Script | What it covers |
|---|---|
| `numpyArray.py` | NumPy array operations and basics |
| `dataFrame.py` | Pandas DataFrame creation and manipulation |
| `missingValue.py` | Handling missing data in a dataset |
| `trainTest.py` | Train/test split for model evaluation |
| `linearRegression.py` | Basic linear regression implementation |
| `accuracy.py` | Model accuracy metrics |

These are practice scripts, not an end-to-end project — see the flagship project 
(coming Week 2) for an applied version of these concepts.
